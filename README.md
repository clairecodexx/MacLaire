# MacLaire

## Overview

MacLaire is a unique, instruction-based language interpreted via Python. It uses a specific syntax designed to be intentionally unconventional.

## Quick Start

1. Ensure you have **Python 3.x** installed.
2. Every script must begin with `execute {self}`.
3. Variables must be declared with `existe` before use.

## Basic Syntax

* **Input**: `choise < variable / int > with message <"Enter number: "> give to x`
* **Output**: `imprimate <"Hello World">`
* **Assignment**: `x give to 10 + 5`
* **Blocks**: Use `/` to open and close logical blocks.
